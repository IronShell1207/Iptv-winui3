# IPTV Client

Домашний IPTV-плеер для Windows на WinUI 3: загружает M3U-плейлист, показывает каналы
с телепрограммой и играет живой MPEG-TS через FFmpegInteropX.

## Требования

- Windows 10 1809+ или Windows 11, x64 либо arm64
- .NET 8 SDK
- Visual Studio 2022 с рабочей нагрузкой «Разработка классических приложений .NET»
  (или только SDK — сборка из командной строки работает)

## Сборка и запуск

```bash
dotnet build IptvPlayer.slnx -p:Platform=x64
```

```bash
dotnet test src/IptvPlayer.Tests/IptvPlayer.Tests.csproj
```

Приложение упаковывается в **MSIX** (single-project packaging): манифест лежит
в `src/IptvPlayer/Package.appxmanifest`, иконки — в `src/IptvPlayer/Assets`.

### Запуск на своей машине

Нужен включённый режим разработчика (Параметры → Система → Для разработчиков).
После сборки пакет регистрируется прямо из папки вывода, без подписи:

```bash
powershell -c "Add-AppxPackage -Register 'src/IptvPlayer/bin/x64/Debug/net8.0-windows10.0.26100.0/win-x64/AppxManifest.xml'"
```

Дальше «IPTV Client» запускается из меню «Пуск». Удалить:

```bash
powershell -c "Get-AppxPackage IptvPlayer.Home | Remove-AppxPackage"
```

### Сборка устанавливаемого пакета

```bash
dotnet build src/IptvPlayer/IptvPlayer.csproj -p:Platform=x64 -p:GenerateAppxPackageOnBuild=true -p:AppxPackageDir=artifacts/msix/
```

Получится `artifacts/msix/…/IptvPlayer_1.0.0.0_x64_Debug.msix` (около 100 МБ:
Windows App SDK и FFmpeg лежат внутри, поэтому на целевой машине ничего
доустанавливать не нужно). Для установки на другом компьютере пакет надо
подписать сертификатом и добавить его в «Доверенные лица» — рядом с пакетом
build кладёт готовый скрипт `Add-AppDevPackage.ps1`, который это делает.

## Настройка

Плейлисты добавляются на главном экране: M3U по ссылке, Xtream Codes (сервер + логин +
пароль) или локальный файл. Значения по умолчанию рассчитаны на связку OpenWrt + udpxy:

| Что | Значение по умолчанию |
|---|---|
| Плейлист | `http://192.168.3.1/iptv.m3u` |
| Телепрограмма (XMLTV) | `http://streamer.mkpnet.ru/epg_service.xml` |
| udpxy | `http://192.168.3.1:4022` |

Если в плейлисте есть атрибут `url-tvg`, адрес телепрограммы берётся оттуда — отдельно
указывать его не нужно.

В настройках задаются адрес udpxy, режим источника (через udpxy или прямой мультикаст),
размер буфера, аппаратное декодирование, сведение звука в стерео, запуск с последнего
канала, период обновления телепрограммы и уровень журнала.

### Режим источника

По умолчанию поток идёт через udpxy: `http://192.168.3.1:4022/udp/239.195.65.33:1234`.
Переключатель «прямой мультикаст» на лету превращает такой адрес в `udp://@239.195.65.33:1234`.
Прямой режим работает только на проводном подключении с включённым IGMP — по Wi-Fi
HD-каналы рассыпаются.

## Данные приложения

Всё лежит в `%LOCALAPPDATA%\Packages\IptvPlayer.Home_…\LocalState`:

- `settings.json`, `session.json` — настройки и последняя сессия
- `playlists.json`, `favorites.json` — плейлисты и избранное
- `playlists/*.m3u`, `epg/*.xml`, `logos/` — кэш
- `logs/app.log` — журнал с ротацией (5 файлов по 2 МБ)

При первом запуске пакета настройки, плейлисты и избранное переносятся из папки
`%LOCALAPPDATA%\IptvPlayer`, где их держала версия без упаковки.

## Управление

| Клавиша | Действие |
|---|---|
| `Пробел`, `K` | Пауза и продолжение |
| `F`, `F11` | Полный экран |
| `Esc` | Выход из полного экрана, затем закрытие плеера |
| `↑` `↓` | Предыдущий и следующий канал (в полноэкранном режиме) |
| `PgUp` `PgDn` | Предыдущий и следующий канал (всегда) |
| `Backspace` | Вернуться к предыдущему каналу |
| `←` `→` | Показать и спрятать список каналов (в полноэкранном режиме) |
| `C` | Закрепить и убрать список каналов |
| `+` `−`, `Ctrl+↑` `Ctrl+↓` | Громкость (то же делает колесо мыши над кадром) |
| `M` | Выключить звук |
| `A` | Следующий режим вписывания кадра |
| `P` | Окно поверх остальных |
| `D` | В избранное |
| `R` | Переподключиться к потоку |
| `0`–`9` | Ввод номера канала |
| `Ctrl+F` | Поиск по каналам |

При изменении громкости с клавиатуры, колесом мыши или кнопкой у правого края
появляется вертикальная шкала с текущим уровнем и прячется через полторы секунды.

### Панели плеера

Панель каналов и панель управления прячутся через 3 секунды без движения мыши.
Панель каналов возвращается наведением курсора к левому краю, панель управления —
любым движением мыши. Кнопка «Список каналов» справа закрепляет панель, пока её не
нажмут повторно. Пока курсор лежит на панели, она не исчезает.

Видео занимает всё окно, включая полосу заголовка: за верхнюю полосу окно по-прежнему
перетаскивается, а часы сдвинуты ниже кнопок окна. В полноэкранном режиме полоса
заголовка убирается, а сверху по центру всплывает кнопка выхода — как в веб-плеерах.

Двойной щелчок по кадру разворачивает видео на весь экран; по кнопкам и спискам он
ничего не переключает, чтобы быстрые клики не открывали полный экран случайно.

Макет подстраивается под ширину окна и состояние панели: название канала и кнопки
управления сдвигаются, освобождая место открытому списку, на узком окне панель
становится уже, «далее» и второстепенные кнопки убираются, а подписи мельчают.

### Вписывание кадра

Кнопка рядом с полноэкранным режимом перебирает четыре варианта: по размеру окна
(с полями), заполнить с обрезкой, растянуть на всё окно и оригинальный размер.
Выбранный режим ненадолго показывается плашкой в правом верхнем углу и сохраняется
между запусками. Рядом стоит кнопка, раскрывающая список каналов.

### Запись эфира

Кнопка записи в панели плеера предлагает два режима:

- **Записать передачу до конца** — запись останавливается сама, когда закончится
  текущая передача по телепрограмме, плюс запас в несколько минут (настраивается).
- **Записать вручную** — пишет, пока не остановят кнопкой.

Поток сохраняется как есть, без перекодирования: с udpxy приходит готовый MPEG-TS.
Запись идёт отдельным соединением, поэтому переключение канала и даже закрытие
плеера ей не мешают. Файлы складываются в `Видео\IptvPlayer` (папка настраивается),
вкладка «Записи» показывает готовые файлы и то, что пишется сейчас.

### Пауза живого эфира

Пауза не теряет эфир: пока она стоит, канал пишется на диск вторым соединением,
и после продолжения вы смотрите с того момента, где остановились, а не с обрыва.
На экране видно, с какого времени копится запись. Если пауза затянулась дольше
выбранного запаса, воспроизведение продолжится с самого раннего сохранённого
момента, о чём появится короткая плашка.

Дальше вы смотрите с отставанием от эфира — его видно вместо надписи LIVE,
а кнопка «В эфир» возвращает к прямой трансляции. Кеширование на паузе включено
по умолчанию, глубина настраивается.

### Отмотка эфира назад

Если включить буфер в настройках, приложение пишет текущий канал в кольцевой
буфер на диске (глубина настраивается, по умолчанию 30 минут). В панели плеера
появляются кнопки «назад» и «вперёд» на полминуты, а вместо надписи LIVE видно,
насколько мы отстали от эфира; кнопка «В эфир» возвращает к прямой трансляции.

Буфер тоже пишется отдельным соединением, то есть канал идёт с роутера дважды.
На проводной сети это незаметно, по Wi-Fi буфер лучше держать выключенным —
поэтому он и выключен по умолчанию.

### Логотипы каналов

Логотип берётся из `tvg-logo`, а если в плейлисте его нет — из элемента `<icon>`
телепрограммы. Скачанные логотипы лежат в дисковом кэше; каналы, для которых логотипа
нет нигде, показываются с инициалами.

## Устройство решения

```
src/
  IptvPlayer/          WinUI 3: окно, оболочка, страницы, плеер
  IptvPlayer.Core/     парсеры и сервисы без зависимостей от UI
  IptvPlayer.Tests/    xUnit на Core
```

`IptvPlayer.Core` не ссылается на WinUI, поэтому парсеры M3U и XMLTV, преобразование
адресов и выбор текущей передачи покрыты тестами без запуска интерфейса.

Иконки — векторные контуры в `Styles/Icons.xaml`, их рисует контрол `SvgIcon`.
Иконочные шрифты не используются: контуры перекрашиваются под тему и состояние кнопки.

## Известные ограничения

- Живой MPEG-TS не имеет длительности, поэтому перемотки нет: вместо таймлайна
  показывается прогресс текущей передачи из телепрограммы.
- Телепрограмма сопоставляется с каналами по `tvg-id`; для каналов без него
  «сейчас в эфире» не показывается.
- Плейлист и телепрограмма провайдера доступны только из домашней сети.
- Переподключение при смене сети (`NetworkStatusChanged`) не сделано — поток
  восстанавливается кнопкой «Повторить» или переключением канала.
- Записи не планируются заранее: запись начинается только с открытого канала,
  расписания на будущие передачи нет.
- Отмотка перескакивает между отрезками буфера по пять минут, поэтому в момент
  перехода бывает короткая пауза.
